# Using Generative AI Tools - Boon or Bane

This repository organises files for the study “Using Generative AI Tools - Boon or Bane”. The folders contain drafts and reports, literature, supporting materials, qualitative work, and quantitative work.

Collaborators should put new files in the appropriate folder, use descriptive file names and commit messages, and keep identifiable participant data out of this public repository.

1. Storage and Accessibility: Explain why it is important to store and organise your files efficiently.

Answer: Organising files into clear folders makes them easier to find and reduces confusion between different versions. It also helps researchers share, review and preserve their work.

2. File Storage Methods: Specify which data types may require special access controls. Explain your reasons (2–3 sentences).

Answer: Interview transcripts, consent forms and raw survey responses may contain personal or identifiable information. These materials should be stored securely and accessed only by authorised researchers, rather than uploaded with real participant details to a public repository.

3. Why is it important to have a good naming convention?

Answer: Consistent, descriptive file names show what a file contains and help everyone find the correct version. Including a document type, topic and date or version number also makes collaboration easier.

4. Under what scenarios would creating a new branch be useful? (2–3 sentences)

Answer: A new branch is useful when testing a different analysis method or changing the folder structure without affecting the main version. Once the work has been checked, the changes can be reviewed and merged into the main branch.
